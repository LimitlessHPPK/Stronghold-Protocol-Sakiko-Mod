# 本地修改清单（相对上游 v0.1.4）

这份文档给**想对照上游**的人：本版改过哪些文件、新增了哪些文件、哪些是「必须一起改」的连带项。
上游原版：<https://github.com/sganggs/Stronghold-Protocol>（`releases/tag/v0.1.4`）。
上游原版的说明保留在仓库根的 `README-上游原版.md`。

> 升级到更新的上游版本时**不要整目录覆盖**：上游会改动同样的文件，盲目覆盖会回退官方修正。
> 请按本清单逐功能移植。

| 文件 | 改了什么 |

| 计数类测试 | `test/data.test.js`、`test/match/{loadout,pool}.test.js`、`test/sim/loadout.test.js`、`test/ui/{loadout,loadout.e2e,gameLogic}.test.js`、`test/render/issue25-downback.test.js` 等因她而变的断言 |

### 生成物（改数据后需重跑）

```
data/{chess,bonds}.json                  ← node tools/build-data.mjs（注入后）
data/assets.json                         ← node tools/fetch-voice-override.mjs + fetch-assets.mjs --offline
docs/research/07-assets.json             ← node tools/add-sakiko-assets.mjs
test/golden/{roster,bonds,fields,matches}.json  ← node tools/golden.mjs --update
```

她的 golden 基线因她重算过三次（加入她、修 6 处缺陷、音符改用官方飞行模型），每次都有 9–11 个含她的场景变化、其余逐位不变。

## 二、通用改进（与干员无关）

| 文件 | 改了什么 |
|---|---|
| `server/index.js` | `DEFAULT_BIND_HOST = '::'` + 绑定回退（`EAFNOSUPPORT` / `EADDRNOTAVAIL` / `EINVAL` → `0.0.0.0`）+ `boundHost`；`lanUrls` 输出带方括号的 IPv6、跳过 `fe80::`、按 /64 去重；`/dev/grant` 路由接线 |
| `server/dev-grant.js` | **新增**：调试端点（四道闸：开关、回环、阶段、正规获取路径）。用法见 `docs/DEV-GRANT.md` |
| `tools/doctor.mjs` | 地址分类扩成 IPv4+IPv6（`ipv6Head` / `classifyV6` / `hostUrl`），默认 host 改 `::` |
| `scripts/launch.mjs`、`run-server.cmd`、`install-service-windows.ps1`、`Dockerfile` | 默认 host 改 `::` |
| `scripts/{public-ipv6,check-public-ipv6}.ps1`、`start-public-ipv6.bat` | **新增**：公网 IPv6 的防火墙 / 自检 / 计划任务辅助（`.ps1` 带 BOM、`.bat` 纯 ASCII） |
| `scripts/fetch-gamedata.ps1`、`scripts/gen-level-list.mjs`、`scripts/gamedata-levels.txt` | **新增**：走 jsDelivr 取官方数据表（本机 `raw.githubusercontent.com` 不可达）；关卡清单已规范成**上游实际使用的小写文件名** |
| `docs/IPV6.md`、`docs/DEV-GRANT.md` | **新增**文档 |
| `public/js/render/{projection,app}.js`、`public/js/render/app/tune.js` | **地图缩放 / 平移**：`ZOOM_MIN/MAX`、相机感知的每格像素上下限、`clampPan` / `panCamera` / `zoomedPan`、相机拆分 `camBase × cam`、滚轮 / 双指 / 中键 / Alt+左键 / 双击复位 |
| `public/js/screens/game.js`、`public/js/screens/game/early.js`、`public/js/audio.js` | **进战场音效修复**：重放时把整份早期事件交给音频；单位未知的技能事件暂存并在认出后补播一次 |
| `server/sim/content/traitMods.js` | **新增**：模组特性里「攻击范围内存在 N 名及以上敌人时攻击速度 +X」这类条件词条的**引擎通用消费**（无干员白名单；读不出条件就不装；手写实现过的形状显式拒绝以避免重复加成） |
| `server/sim/Battle.js` | 接线 `installTraitAttackSpeed`（在 `kit.install` 之后） |
| `server/sim/content/kits/tier5.js` | 删掉 `crowdAspd`（圣约送葬人 / 隐德来希的重复实现），改由引擎接管 |
| `public/js/ui/gameLogic.js` | 设置默认值（音乐 100% / 音效 75% / 画质 中）+ `SETTINGS_VERSION` / `SETTINGS_MIGRATIONS`（只改写仍等于旧默认值的项） |
| `.gitignore` | 忽略临时提交信息文件 `.tmp-msg-*.txt` |
