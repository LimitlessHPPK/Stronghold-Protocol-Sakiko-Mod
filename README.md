# 卫戍协议：盟约 · 丰川祥子 Mod（基于上游 v0.2.1）

明日方舟「卫戍协议：盟约」（1–4 人合作自动棋）的**非官方同人网页复刻**，基于上游
[**sganggs/Stronghold-Protocol**](https://github.com/sganggs/Stronghold-Protocol) 的 **v0.2.1** 制作的**本地修改版**：

- **新增可选干员「丰川祥子」**（`char_4182_oblvns`，Ave Mujica 联动 6★ 领主）——走 v0.2.x 的**「自选编队」**路线；
- 若干**手感与音画修复**（地图缩放/平移、进战场音效、模组攻速词条）；
- 服务器 **IPv6 双栈**与一个**可选的本地调试端点**。

> **不是官方作品**，与鹰角网络 / 悠星无任何关联；仓库**不含任何官方美术与音频素材**（见文末「素材与版权」）。
> 代码许可沿用上游 **GPL-3.0-or-later**（`LICENSE` / `NOTICE.md` / `THIRD-PARTY-NOTICES.md`）。
> 上游原版说明完整保留在 **`README-上游原版.md`**；逐文件改动清单见 **`docs/本地修改清单.md`**。

## 一、怎么玩到丰川祥子（重点）

v0.2.x 有「**自选编队**」系统，她走这条路——**不会出现在公共卡池里**：

1. 标题页 →「**干员调配**」→ 第三个标签「**自选编队**」；
2. 把她放进 **6 阶**（或 5 阶）的某个槽位：**三个技能任选**；放进**精锐槽**还能**选模组**（推荐 **LOR-Y「无言的约定」**）；
3. 开局后她只会出现在**你自己的商店**里，刷出的外观是「**甄选干员**」（价格 4）；
4. **门槛**（数据里的硬要求）：

| 你放的槽 | 商店里什么时候能刷出她 |
|---|---|
| 6 阶槽（两个） | **调度中心 6 级**起 |
| 5 阶槽（两个） | **调度中心 5 级**起 |

> 编队是**开局冻结**的：局中改动**下一局**才生效。
> 因为官方数据里没有她，她是靠 `tools/inject-sakiko.mjs` 的**注入**（幂等）进入自选池的。

### 她的机制（按官方 / PRTS 实现）

| 机制 | 实现要点 |
|---|---|
| **音符即普攻载体** | 普通攻击**没有可见箭矢**，伤害与攻击回复技力都在**音符命中时**结算；命中判定**不含伤害量**（护盾全吃、闪避、无敌也算击中；没打到人不加） |
| **持续攻击** | 射程内**没有敌人也会持续发射音符**（PRTS 术语）。唯一限制：**前方一格通行类型为「无」**（越界或该格 `pass === 'NONE'`；**障碍物同样挡**，「只走不飞」的地块不挡） |
| **音符运动** | 官方三态模型：**【自由移动】**（扩张正弦漂移）/ **【追踪移动】**（带转向速度）/ 命中即消失（官方两张参数表里都写「不存在【已命中】」）；非技能期间初始方向为**朝向左 20° 至右 20° 随机** |
| **Fever（天赋二）** | 计量 **0–450 点**（界面显示百分比）；**蓄满后任意一次技能发动**即进入 **20 秒 Fever**，**在场全员**一起进入；期间 **Fever 不再累积 / 不再回复技力 / 常规自动发动被压制**，只做 Fever 驱动的释放（**不消耗技力、无视技力限制**，切换类二技能除外）；进入前已在跑的持续类技能**暂停计时**，凭 Fever 开启的持续类技能在**结束时强制结束**。进度**只在本次战斗内保留**（新回合、联防协助各自从 0 开始） |
| **天赋一（穿甲）** | 每存在一个音符，Ave Mujica 成员无视敌人 **3% 防御 / 2% 法术抗性**（最多 **10 层**）；**LOR-Y 2 级 → 4%/2%、12 层；3 级 → 5%/2.5%、12 层**；命中目标的那只音符也计入层数 |
| **三个技能** | **S1 新月的苏醒**：演奏 8 个音符（法术伤害自攻击力 65% 递减至 4%），可充能 2 次、充能满自动释放一次（**不计入 Fever 触发**）；**S2 满月的舞会**：切换类，钢琴（+攻击、音符物理穿透）/ 风琴（+攻速、音符法术并减速），**Fever 期间二连击**；**S3 残月的余响**：范围扩大、钢琴+风琴各 2 个音符（各 180%），**追踪法抗最高 / 防御最高的敌人**，**Fever 期间免死**（被救者退场） |
| **模组** | 她的数据里只有两个模组：**证章**（`uniequip_001_oblvns`）与 **LOR-Y「无言的约定」**（`uniequip_002_oblvns`）。LOR-Y 的「**技能期间远程攻击不再降低攻击力**」（2/3 级）已实现；它的「攻击范围内存在 2 名及以上敌人时攻击速度 +12」由**引擎通用规则**提供（见下） |
| **语音** | **日语**。原因：她所属联动（Ave Mujica）的**中文配音在上游资源里不存在**（整个联动的 CN dump 都是 404、JP dump 正常） |
| **界面** | 模型右下角的**玫红进度图标**（蓄满有光效；Fever 期间显示剩余时间百分比），Fever 期间她的 **SP 条染成玫红**；音符在战场上**可见**（八分/十六分/高音谱号三种字形，命中后淡出回收） |
| **盟约归属** | 只有**协防**（`emptyShip`）——官方数据里没有她的盟约字段；她不会进公共卡池，所以也不占盟约成员名额 |

## 二、本版相对上游 v0.2.1 的其它改动

| 项目 | 说明 |
|---|---|
| **模组「攻速词条」修复** | 模组特性里形如「攻击范围内存在 2 名及以上敌人时攻击速度 +12」的条件词条**此前完全没人读**（数值在特性黑盒里、条件只写在文案里）。现在由引擎**通用消费**（**没有干员白名单**），顺带修好了官方干员**圣约送葬人**与**隐德来希**的 REA-Y 模组；其余条件形状仍由各自实现负责，引擎显式拒绝以避免重复加成 |
| **地图缩放 / 平移** | 滚轮以**指针为锚点**缩放（0.5×–3×，并按各机位限制每格 9–190 px）；触控板横向、**中键拖拽**、**Alt+左键拖拽**平移；**双指捏合**缩放 + 拖动；**双击复位**。有边界保护，换机位 / 改变窗口时保留缩放、清空平移 |
| **进战场音效修复** | 进入**已经打起来**的场地（观战 / 重连 / 队友的场地）时，过去的事件只把 `spawn` 交给音频，导致**部署当帧就发动的技能没有声音**；现在整份事件都交给音频，并且「事件早于单位到达」时会暂存、认出单位后补播一次（普通对局里部署当帧的发动同样受益） |
| **IPv6 双栈默认** | 默认绑定 `::`（同时接受 IPv4 与 IPv6）；不支持时回退 `0.0.0.0` 并报告**实际绑定**的地址。地址清单 IPv6 带方括号、跳过 `fe80::`、按 /64 去重；`npm run doctor` 与部署文档同步。附公网 IPv6 辅助脚本（见 `docs/IPV6.md`） |
| **设置默认值与迁移** | 默认值调为 音乐 **100%** / 音效 **75%** / 画质 **中**；带**版本化迁移**，且**只改写仍然等于旧默认值的项**（玩家自己调过的不会被覆盖） |
| **调试端点（可选，默认关闭）** | `SP_DEV_GRANT=1` 启动后，**只接受本机回环**请求：给玩家发棋子 / 发资金 / **强制指定自选编队**（没选人也能发）/ **设置盟约层数**。四道安全闸：开关 / 回环 / 只在整备·结算阶段 / 走**正规获取路径**。用法见 `docs/DEV-GRANT.md`。**它是调试口：会让库存与层数的账目不真实，不要据此判断平衡** |

## 三、安装与运行

需要 **Node.js ≥ 22**（`package.json` 的 `engines`）。

```bash
npm install          # 安装依赖（postinstall 会生成 public/vendor）
npm run assets       # 下载官方素材到 public/assets（约 270 MB，需要联网）
npm start            # 启动服务器，默认 http://localhost:3000
```

然后浏览器打开 `http://localhost:3000`（局域网/公网地址见启动时打印的清单；本版默认双栈，IPv6 可直接用 `http://[地址]:3000`）。

```bash
npm run doctor       # 环境自检（地址、端口、依赖、素材是否齐备、文件校验）
npm test             # 完整测试套件（注意：fullmatch 系列每个文件要 9–11 分钟，建议 --test-concurrency=3）
npm run golden       # 黄金基线：固定种子场景逐位对比
```

### 她的语音需要单独取一次

资源清单（`data/assets.json`）已经指向 `/assets/audio/voice/jp/...`，但**语音文件本身**要单独获取：

```bash
node tools/fetch-voice-override.mjs          # 取她缺失的 14 条语音
node tools/fetch-voice-override.mjs --sfx    # 顺带取她的 7 个技能音效
```

脚本默认走 `https://gh-proxy.com/` 镜像（可用环境变量 `SP_GITHUB_PROXY` 更换），因为上游语音分支没有
jsDelivr 镜像、且部分网络环境无法直连 `raw.githubusercontent.com`。取完可跑
`node tools/fetch-assets.mjs --offline` 重建清单（通常不必）。

### ⚠️ 不要用官方「增量更新包」升级本仓库

上游从 v0.2.1 起提供只含改动文件的**增量更新包**，它启动时会按 `MANIFEST.json` 校验程序文件——
**本仓库的程序文件是改过的**，会被判定为"不是整合包"而拒绝启动。升级请用**完整包 + 按
`docs/本地修改清单.md` 逐功能移植**（`AGENTS` 的教训：永远不要整目录覆盖）。

## 四、已知取舍（与官方有出入的地方）

完整清单与出处见 **`docs/research/12-sakiko.md`**（含 PRTS 引用、逐条数值、全部简化说明）。最需要知道的几条：

1. **S2/S3 技能期间**每次攻击仍是「技能音符 + 天赋音符」**两层**（官方模型下这段时间的载体应当只有技能自己那只）——**暂未合并**。
2. **「其他 Ave Mujica 成员的攻击范围延伸」不实现**（本项目没有其他联动成员；PRTS 备注里"第二只她自己也算"的情形同样按现状处理）。
3. **音符外观**是程序化绘制的（官方特效美术未提取）；Fever 图标的尺寸/描边为观感取值（内圈单环、蓄满光效、**无 50% 刻度**）。
4. 几处**观感/概率取值**标了 `[ASSUMED]`：S1 音符间隔、Fever 驱动释放的间隔（1.5 s）、部分音色与档位的绑定方式（数值取自各自档位黑盒）。
5. **英文界面下她的文本回落中文**（官方英文服还没有她的文本）；**语音是日语**（官方没有中文配音）。
6. **LOR-Y 2 级在自选编队路径上不可达**（槽位的模组等级只有 1 与 3）；引擎与她的实现都按数据判定，将来数据出现 2 级形态也会自动生效。
7. **盟约**：她只有协防归属，且不在公共卡池。
