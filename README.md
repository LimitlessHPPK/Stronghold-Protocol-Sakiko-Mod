# 卫戍协议：盟约 · 本地修改版 v0.1.4

明日方舟「卫戍协议：盟约」（1–4 人合作自动棋）的**非官方同人网页复刻**，基于上游
[**sganggs/Stronghold-Protocol**](https://github.com/sganggs/Stronghold-Protocol) 的 `v0.1.4`
制作的**本地修改版**：新增一名可选干员、修复若干手感与音画问题、并给服务器加上 IPv6 双栈支持。

> **不是官方作品**，与鹰角网络 / 悠星无任何关联；仓库**不含任何官方美术与音频素材**（见文末「素材与版权」）。
> 代码许可沿用上游 **GPL-3.0-or-later**（`LICENSE` / `NOTICE.md` / `THIRD-PARTY-NOTICES.md`）。
> 上游原版说明完整保留在 **`README-上游原版.md`**；逐文件改动清单见 **`docs/本地修改清单.md`**。

## 本版相对上游 v0.1.4 的修改

### 一、新增干员：丰川祥子（`char_4182_oblvns`，6★ 领主）

三个技能齐备，按官方（PRTS）机制实现，含她被官方数据注释描述过的整套「Fever / 音符」体系：

| 机制 | 实现要点 |
|---|---|
| **音符即普攻载体** | 普通攻击**没有可见箭矢**，伤害与攻击回复技力都在**音符命中时**结算；命中判定**不含伤害量**（护盾全吃、闪避、无敌也算击中；没打到人则不加） |
| **持续攻击** | 射程内**没有敌人也会持续发射音符**（PRTS 术语）。唯一限制是**前方一格通行类型为「无」**（越界或该格 `pass === 'NONE'`；**障碍物同样挡**，「只走不飞」的地块不挡） |
| **Fever（天赋）** | 计量 **0–450 点**（界面按百分比显示）；**蓄满后任意一次技能发动**即进入 **20 秒 Fever**，且**在场全员**一起进入；期间 **Fever 不再累积 / 不再回复技力 / 常规自动发动被压制**，只做 Fever 驱动的释放（**不消耗技力、无视技力限制**，切换类二技能除外）；进入前已在跑的持续类技能**暂停计时**，凭 Fever 开启的持续类技能在**结束时强制结束**。进度**只在本次战斗内保留**（新回合、联防协助各自从 0 开始） |
| **三个技能** | 一技能：固定扇形音符（自左 13.125° 至右 13.125°、步进 3.75° 顺时针）+ 充能满自动释放（不计入 Fever 触发）；二技能：切换类，音色改变，Fever 期间二连击；三技能：按属性索敌 + 免死（优先级 −3000，被救者退场） |
| **模组与形态** | LOR-X / LOR-Y 均可选，精锐形态可选模组；模组数值按形态自动生效（含 LOR-Y 三级的 0.05 / 0.025 / 12） |
| **语音** | **日语**。原因：她所属联动（Ave Mujica）的**中文配音在上游资源里不存在**（整个联动的 CN dump 全部 404、JP dump 正常），故按日语接入 |
| **界面** | 模型右下角的**玫红进度图标**（蓄满有光效；Fever 期间显示剩余时间百分比），并且 Fever 期间她的 **SP 条染成玫红** |

> 两个**已知未做**（观感层面，不影响玩法）：技能期间的「技能音符 + 天赋音符」仍是两层、未合并；
> 音符**飞行途中**的外观为本版自绘（服务端权威位置 + 客户端按快照绘制）。

### 二、手感与音画修复（通用，与干员无关）

| 项目 | 说明 |
|---|---|
| **地图缩放 / 平移** | 滚轮以**指针为锚点**缩放（0.5×–3×，并按各机位限制每格 9–190 px）；触控板横向滚轮、**中键拖拽**、**Alt+左键拖拽**平移；**双指捏合**缩放 + 拖动；**双击复位**。有边界保护（基准画面中心永不离开视口），换机位 / 改变窗口时保留缩放、清空平移 |
| **进战场音效修复** | 进入**已经打起来**的场地（观战 / 重连 / 队友的场地）时，过去的事件只把 `spawn` 交给音频，导致**部署当帧就发动的技能没有声音**；现在整份事件都交给音频，并且「事件早于单位到达」时会暂存、认出单位后补播一次 |
| **模组「攻速词条」修复** | 模组特性里形如「攻击范围内存在 2 名及以上敌人时攻击速度 +12」的条件词条**此前完全没人读取**（数值在特性黑盒里、条件只写在文案里）。现在由引擎**通用消费**（**没有干员白名单**），顺带修好了官方干员**圣约送葬人**与**隐德来希**的 REA-Y 模组；其余条件形状仍由各自实现负责，引擎显式拒绝以避免重复加成 |

### 三、服务器与工程

| 项目 | 说明 |
|---|---|
| **IPv6 双栈默认** | 默认绑定 `::`（同时接受 IPv4 与 IPv6）；不支持时按 `EAFNOSUPPORT` / `EADDRNOTAVAIL` / `EINVAL` 回退 `0.0.0.0`，并报告**实际绑定**的地址。地址清单 IPv6 带方括号、跳过 `fe80::`、按 /64 去重；`npm run doctor`、部署文档与 Docker 同步更新。附公网 IPv6 辅助脚本（见 `docs/IPV6.md`） |
| **`/dev/grant` 调试端点** | 本地调试用：给已入座玩家发棋子 / 金币 / 临时区副本。**四道安全闸**：`SP_DEV_GRANT=1` 才挂载、**只接受回环地址**、**只在整备 / 结算阶段**、走**正规获取路径**（池子与合成规则、费用都由既有代码决定）。用法见 `docs/DEV-GRANT.md` |
| **设置默认值与迁移** | 默认值调为 音乐 **100%** / 音效 **75%** / 画质 **中**；带**版本化迁移**，且**只改写仍然等于旧默认值的项**（玩家自己调过的设置不会被覆盖） |

## 安装与运行

需要 **Node.js ≥ 22**。

```bash
npm install          # 安装依赖（postinstall 会生成 public/vendor）
npm run assets       # 下载官方素材到 public/assets（约 270 MB，需要联网）
npm start            # 启动服务器，默认 http://localhost:3000
```

然后浏览器打开 `http://localhost:3000`（局域网内的朋友访问启动时打印的 LAN 地址）。

```bash
npm run doctor       # 环境自检（地址、端口、依赖、素材是否齐备）
npm run launch       # 启动并打印可分享的地址
npm test             # 完整测试套件
npm run golden       # 黄金基线：固定种子场景逐位对比
```

### 她的语音需要单独取一次（重要）

资源清单（`data/assets.json`）已经指向 `/assets/audio/voice/jp/...`，但**语音文件本身**要单独获取：

```bash
node tools/fetch-voice-override.mjs          # 取她缺失的 14 条语音
node tools/fetch-voice-override.mjs --sfx    # 顺带取她的 7 个技能音效
```

脚本默认走 `https://gh-proxy.com/` 镜像（可用环境变量 `SP_GITHUB_PROXY` 更换），因为上游语音分支没有
jsDelivr 镜像、且部分网络环境无法直连 `raw.githubusercontent.com`。若你的网络能直连，也可照常使用
`npm run assets` 的下载器（部分机器上需要给 Node 加 `--use-system-ca`）。
